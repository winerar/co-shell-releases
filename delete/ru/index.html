Удаление данных

Данные на телефоне

Удалите приложение — данные на телефоне исчезнут. Или нажмите «Стереть все данные» в разделе «Ещё → Резервная копия».

Облако семьи

  • «Ещё → Семья → Выйти из семьи»: вы перестанете видеть общие данные, на телефоне они останутся.
  • «Ещё → Семья → Удалить семью» (для владельца семьи): общие данные удалятся из облака у всех участников.

Не получается удалить

Напишите нам из приложения: «Ещё → Отзыв». Укажите, какие данные удалить; ответим и удалим в разумный срок.
